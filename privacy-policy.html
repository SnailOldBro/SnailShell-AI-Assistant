蜗牛壳AI助理 · 隐私政策

SnailShell AI Assistant — Privacy Policy

生效日期：2026-09-30

1. 概述

蜗牛壳AI助理（以下简称"本扩展"）是一款浏览器侧边栏工具，用于总结网页、基于页面上下文提问、以及引用选中文字向 AI 提问。我们坚持"数据最小化"原则：本扩展不运营任何用于收集用户数据的服务器。

2. 我们收集的数据

我们不收集您的个人数据。本扩展不会向开发者或任何第三方服务器传输您的浏览内容、对话记录、API Key 或设备信息。我们没有分析 SDK、没有遥测、没有广告追踪。

3. 数据如何被使用与传输

当您主动使用"总结本页""页面提问"或"引用选中内容提问"时，当前页面的正文或您选中的文字会被发送到您在设置中自行配置的 AI 服务（如 DeepSeek、Qwen、GLM、Kimi、Ollama，或任意 OpenAI 兼容 endpoint），并使用您自己的 API Key，通过 HTTPS 直连该服务。

  • 数据不经过任何第三方中转服务器，也不经过开发者服务器。
  • 如果您未配置任何模型，本扩展不会向任何外部服务发送数据。
  • 发送的内容范围仅限您当前已渲染的页面正文或主动选中的文字。

4. API Key 的存储

您的 API Key 仅保存在您本地浏览器的扩展存储（chrome.storage.local）中：

  • 明文模式（默认）：Key 以明文存于本机，便于重开浏览器免填。仅本机文件系统完整权限的恶意程序可能读取。
  • 主密码保护（可选）：所有 Key 使用 PBKDF2 + AES-GCM 整体加密后落盘，重开浏览器需输入一次主密码解锁。加密不可逆、无法找回。

开发者无法访问您的 API Key。

5. 对话历史

对话记录仅保存在您的本机扩展存储，不会上传到任何服务器。

6. 我们不会做的事

  • 不收集浏览历史、不读取 Cookie、不获取账号凭据；
  • 不翻页批量抓取、不绕过付费墙、不自动构造请求；
  • 不向开发者或第三方服务器传输任何用户数据；
  • 不出售、不共享任何用户信息。

7. 权限说明

  • sidePanel：提供侧边栏交互界面（总结 / 提问 / 引用）。
  • contextMenus：提供右键菜单「AI 就这段内容提问」「AI 总结选中内容」。
  • storage：在本机保存用户的模型配置与对话历史。
  • activeTab：仅在用户主动点击图标或右键时，访问当前标签页内容。
  • scripting：向页面注入本地的正文提取脚本，用于总结与引用。
  • clipboardWrite：将 AI 回答复制到剪贴板。
  • host_permissions <all_urls>：因需对任意网页读取已渲染正文做总结；仅用户主动触发、仅读取已渲染内容、不外传。

8. 儿童隐私

本扩展不面向儿童，也不故意收集儿童的任何信息。

9. 政策变更

若隐私政策发生变更，我们将更新本页面与生效日期。重大变更会通过扩展更新说明告知。

10. 联系方式

如对本隐私政策有疑问，可通过扩展设置页或项目主页联系开发者。

1. Overview

SnailShell AI Assistant (the "Extension") is a browser side-panel tool that summarizes web pages, answers questions with page context, and lets you quote selected text to chat with an AI. We follow data minimization: the Extension operates no server that collects user data.

2. What we collect

We collect no personal data. The Extension transmits no browsing content, chat history, API keys, or device information to the developer or any third-party server. There are no analytics SDKs, telemetry, or ad trackers.

3. How data is used and transmitted

When you actively use "Summarize this page", "Ask about this page", or "Ask about the selected text", the page's main text or your selected text is sent to the AI service you configure yourself in settings (e.g. DeepSeek, Qwen, GLM, Kimi, Ollama, or any OpenAI-compatible endpoint), using your own API key, over HTTPS directly to that service.

  • Data passes through no third-party relay and no developer server.
  • If you configure no model, the Extension sends nothing to any external service.
  • Only the rendered page text or your explicitly selected text is sent.

4. Storage of API keys

Your API keys are stored only in your local browser extension storage (chrome.storage.local):

  • Plaintext mode (default): keys stored on your device for convenience; only malware with full local filesystem access could read them.
  • Master-password protection (optional): all keys are encrypted with PBKDF2 + AES-GCM before being stored; unlock requires the master password once per browser launch. Encryption is irreversible.

The developer cannot access your API keys.

5. Conversation history

Chat history is stored only in your local extension storage and is never uploaded.

6. What we do NOT do

  • No browsing-history collection, no cookie reading, no credential access;
  • No bulk crawling, no paywall bypass, no automated request construction;
  • No transmission of any user data to the developer or third parties;
  • No sale or sharing of user information.

7. Permissions

  • sidePanel: provides the side-panel UI (summarize / ask / quote).
  • contextMenus: provides right-click menus "Ask AI about this selection" and "Summarize selection".
  • storage: stores your model config and chat history locally.
  • activeTab: accesses the current tab only when you click the icon or right-click.
  • scripting: injects the local content-extraction script for summarizing and quoting.
  • clipboardWrite: copies AI answers to the clipboard.
  • host_permissions <all_urls>: needed to read rendered page text on any site for summarization; triggered only by the user, reads only rendered content, sends nothing.

8. Children

The Extension is not directed to children and does not knowingly collect information from children.

9. Changes

If this policy changes, we will update this page and its effective date. Material changes will be noted in the extension update notes.

10. Contact

For questions about this privacy policy, contact the developer via the extension's settings page or project homepage.
